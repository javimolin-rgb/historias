# Historias

Canal de historias animadas de supervivencia en español. El repo produce el video completo:
guion, escenas dibujadas en SVG por código, voz, subtítulos y montaje.

- Reglas del proyecto y estilo: [CLAUDE.md](CLAUDE.md)
- Instalación y comandos: [INSTALAR.md](INSTALAR.md)

```
personajes/    personaje.js (oficial) y páginas del casting
escenas/       fondos por lugar y props/ reutilizables
historias/     NNN-slug/guion.json, audio/, planos/
assets/audio/  música y efectos
scripts/       voz, escenas, video, todo
salida/        videos finales (no se versionan)
```
